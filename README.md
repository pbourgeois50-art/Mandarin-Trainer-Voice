# Mandarin Trainer Voice

Build workspace for Mandarin Trainer Voice v2.4.2.

v2.4.2 imports the course editor from Mandarin Trainer 2.1.11:
- reorder lessons
- reorder words inside a lesson
- move words between lessons
- use the same saved course order in foreground UI and background voice playback

The large offline Paraformer model is downloaded from the upstream Apache-2.0 model repository during CI and is not stored in this repository.
